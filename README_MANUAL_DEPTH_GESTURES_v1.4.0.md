# DepthWallpaper v1.4.2 — Manual Depth Gestures

- No Vision / AI segmentation.
- Wallpaper and cutout no longer need matching pixel dimensions.
- Select any wallpaper and a transparent PNG cutout.
- In the app preview: drag with one finger to move the cutout; pinch with two fingers to scale it.
- Position and scale are saved as normalized metadata and used by the SpringBoard tweak.
- Reset button returns the cutout to the center at scale 1.0.
- Original selected image data is saved without resizing by the picker pipeline when available.
