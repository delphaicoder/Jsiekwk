# DepthWallpaper Manual Depth v1.2.5

This version intentionally removes the Vision/AI segmentation path.

Workflow:
1. Choose the original wallpaper.
2. Choose a transparent PNG that you already prepared.
3. Both files should have the exact same pixel width and height.
4. The PNG is stored without resize/crop when the photo picker provides the original file.
5. The tweak displays the cutout as a full-screen overlay without independent scale/Y-offset.

Landscape is the preferred orientation, portrait remains supported.
